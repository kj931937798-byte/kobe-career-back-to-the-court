## 选图边界与校验

已阅读用户提供的连续章、既有 `historical-photos.md` 与 `chapter-one-photos.md`，并核对 Commons 各原始文件页、学校及达美中心的官方建筑沿革。五张新增照片均宽于3200像素；逐张查看确认无新闻水印或乱码。也比较了2016年同校照片，其内容仍为新校舍且文件更大，因此保留2017年版本。达美中心另比较了2304 × 1296的2016年照片，其正面被树干和车站设施遮挡，最终选用2019年高清正立面照片。

在本轮覆盖的 Commons 科比年份分类及早年照片搜索中，未找到来源和许可足以支持1996—1997年真人照片直接复用的候选。该缺口仍保留；没有以2009、2014等晚期照片替代。选秀和8号人物段使用明确标注的插画，环境段使用不同地点的真实照片。

接口位于 `src/story-media.js`。除约定的 `italy / school / draft / forum / rookie / utah` 外，增加 `cleveland`，仅用于克利夫兰篇章。每项包含 `src / alt / caption / credit / source / license / position / fit`；真实照片另附 `licenseUrl` 与 `kind: 'photograph'`，插画为 `kind: 'illustration'`。
