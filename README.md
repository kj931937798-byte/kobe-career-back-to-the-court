# 重返球场 · 第一章：第十三顺位

一款以科比成长经历为背景的中文互动篮球故事。读过来时的路，在成长对话中留下回答，在关键回合接过篮球。

当前为第一章试玩版。玩家无需登录，使用桌面或手机浏览器即可体验；游戏进度保存在当前浏览器中。

## 本版内容

- 两幕黑金开场，17 页故事，从意大利童年、高中和选秀，走到 1997 年犹他之夜。
- 教练、父亲的两段成长对话，每段四个均成立的回答，不判对错、不改变比赛结算。
- 两次球场选择、对应动画和叙事，以及第一章结果回望。
- 人物简卡、剧情配乐、音量设置、减少动效和本地存档。
- 章节回顾保留 2010 年总决赛抢七独立样章。

完整六章生涯、保罗加盟线和 GOAT 结局尚未开放。第一章的胜利仅指赢下 1997 年第五场，系列赛追到 2∶3，不代表晋级或总冠军。

## 在线游玩

仓库管理员开启 GitHub Pages 后，可从仓库右侧的 `Deployments / github-pages` 或 `Settings → Pages → Visit site` 找到游戏网址。这个 README 不代表网站已部署完成。

已有进度时，“从头阅读第一章”保留成绩并回看故事；“继续上次”回到已存位置。存档不会自动在设备、浏览器或本地测试地址之间同步。请避免为了刷新新版而清理网站数据。

音乐在首次点击后开始播放；如无声，检查游戏音量、浏览器标签页和设备音量。当前好结果音乐为 Scott Buckley 的《Ascension》。

## 部署这个发布包

这是已经构建好的静态网站，根目录 `index.html` 为入口；无需在 GitHub 安装依赖或再次构建。

保持 `assets`、`audio`、`fonts`、`licenses`、`docs` 以及 `.nojekyll` 的层级和文件名。使用 GitHub Pages 时，将 `Settings → Pages` 设置为 `Deploy from a branch`，选择放置这些文件的分支与 `/(root)`。[官方配置说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

网页上传应分批进行，每批最多 100 个文件，单文件不超过 25 MiB；建议将 `fonts` 整个文件夹单独上传，且每批均从仓库根目录发起。[官方上传说明](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)
