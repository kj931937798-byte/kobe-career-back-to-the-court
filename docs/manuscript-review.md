# 《重返球场》第一章上传稿审校与实现记录

审校日期：2026 年 9 月 6 日。

完整阅读了用户上传的《重返球场》第一章：第十三顺位，包括史料表、十七段正文、八项结果及作者说明。先检查项目 README、现有 game.js、chapter-one.js、Court 的动作接口和存档约定，再核对公开资料。原稿中“所有史实已核实”“所有选项不泄露结果”等自检声明不作为证据。

实现保留十七段来时的故事、第二人称、两个选择点及每点四项选择。主要场景顺序没有删减：意大利→回国→高中受挫→州冠军→试训与选秀→洛杉矶新秀生活→全明星周末→两轮季后赛→第五场之夜。保留可用对白、球馆声响、等待和赛后反应；修改明显错误、无出处的特定轶事、替他人断言负面动机，以及选项中提前评价哪条更稳妥的措辞。

## 事实、回忆与创作的界线

- 比赛日期、比分、出场统计优先采用 NBA 原始比赛记录；地方历史用当时公开记录或校方资料辅助核对。
- 记者多年后的回忆只支持其直接讲述的事件，不扩展成未见全文的传记内容。没有直接阅读《Showboat》或《The Mamba Mentality》全文，也没有据此引用页码。
- 对话、心理、家庭和球馆中的感官细节统一按文学创作处理，UI 应显示“依据历史背景改编；心理、对白与细节为情境创作”。不得将对白另列为真实采访引语。
- 第一选择是虚构的队内训练；十人来自真实当季湖人名册，但分组、站位、动作、得分不是某次训练的记录。
- 第二选择以 1997 年 5 月 12 日第四节末 89 平为事实起点。球员位置与不同打法为示意，不声称精确录像复刻。两场都使用 `clock: null`，不显示未经确认的倒计时。
- 正文和选择后叙事不夹入制作说明。`court.illustrationLabel`、`outcome.label`、`bridge` 和章末历史对照负责说明创作边界。

### 官方材料也可能有冲突

NBA 2017 年首秀回顾正文写了 1 次抢断，与该场原始统计、逐球记录不一致；这里采用原始记录的 0 次。NBA 老比赛数据中还出现过使用今天球馆名称、第五场页面内部副字段标成第七场，以及最后跳投动作被粗分为上篮的情况。代码不依据这些异常字段生成历史叙述，不把某个官方页面标签当作免于交叉核对的理由。

## 两个选择点的结果闭合

所有选项只描述眼前观察和准备执行的动作；不放胜率、数值增益、最稳选择或未来结局。第一次选择没有隐藏的“组合密码”，不会强迫第二次失败。

| 节点 / 选项 | 动画停点 | 后续叙事的范围 |
|---|---|---|
| 训练 A | 科比三分不中，布朗特拿篮板；0–0 | 下一组训练，指出接球前的观察；不会因一次失手被永久弃用 |
| 训练 B | 突破分给斯科特，三分命中；3–0 | 描述出手与传球的角色感受 |
| 训练 C | 侧移传奥尼尔，内线得两分；2–0 | 描述低位接应与外线机会并存 |
| 训练 D | 回传尼克，出手不中，布朗特篮板；0–0 | 教练指出回传后的跑位问题；继续训练 |
| 犹他 A | 后撤三分三不沾，马龙拿球；89–89 | 加时后 93–98 失利，系列赛 1–4；三次加时三不沾只作概述，不编造逐球时刻 |
| 犹他 B | 科比中距离命中；91–89 | 爵士最后出手不中，架空赢第五场，系列赛 2–3 |
| 犹他 C | 科比突破分球，尼克三分命中；92–89 | 爵士追平远投不中，架空赢第五场，系列赛 2–3 |
| 犹他 D | 掩护、顺下接球、出手不中；89–89 | 加时后到达 93–98 的历史终点，系列赛 1–4；不伪装成历史上真的发生过这一挡拆 |

`scoreAfter` 只表示动画这一攻结束的比分；`matchResult.score` 表示后续比赛终场比分。因此 A/D 的 89–89 与终章 93–98 不矛盾，`bridge` 显式解释随后加时。章末只回顾本章实际两项选择，附创作球迷反馈与真实历史对照，不结算整个生涯、GOAT 或完美人生。

## 数据与验证

新增文件为 `src/narrative.js`、`tests/narrative.test.mjs`，不替换旧 `chapter-one.js`。

导出 `createNarrativeSave`、`getNarrativePage`、`resolveNarrativeChoice`、`advanceNarrative`、`validateNarrativeSave`、`getNarrativeEnding` 和深冻结的 `NARRATIVE_PAGES`。存档为 `{version:1,cursor,status,history}`；`cursor` 0–16 为正文页，10 和 16 为选择页，17 为本章结束。阅读页直接继续；选择页必须先结算再继续。重复提交或无效操作不改变存档。

所有正文静态，不依赖未来选择。回看可直接读取 `NARRATIVE_PAGES[viewCursor]`，保留真正存档的进度；已做选择只展示或重播原 outcome。页面 getter、结局 getter 和推进/结算都隔离可变引用。验证器从初始状态按已记录的选择重放，逐字段比对完整结果，拒绝伪造比分、正文、动作、额外字段、跳过节点、重排历史和重复结算。

运行 `node --test tests/narrative.test.mjs`，覆盖 17 页 / 两个选择门、16 条完整路线的确定性与 JSON 往返、比分/得分者/球权/动画角色对应、历史关键修正、篡改存档、回看隔离和章节结束边界。页面视觉、素材许可和浏览器联动由主任务验证，不把数据测试描述为已验证全部 UI。

剩余限制：并未声称读取两本传记全文；早年生活的具体动作、家庭对话和第五场球员精确站位仍是创作。全明星页的配图若为后来拍摄的球馆，只可标作环境参照，不可称为 1997 年现场照片。
